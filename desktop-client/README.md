# 💻 SubFlow Desktop 本地桌面客户端 (Windows 便携版)

面向个人电脑的极简订阅流体转换工具，绿色免安装，随开即用。

## 🌟 核心特性
- ⚡ **0 门禁 · 随开即用**：无需注册、无需登录、无需邀请码，双击直接进入转换工作台；
- 🌐 **内置 Cloudflare 远程穿透**：家庭电脑开着，手机在外面随时随地扫码直连家庭电脑更新订阅；
- 📱 **一键客户端唤醒**：无缝唤醒 Clash / Shadowrocket / Sing-box / Surge；
- 🔀 **多源订阅流聚合**：多个机场一键合并为单条动态流，去重提速；
- 🔒 **100% 本地隐私安全**：数据保存在本地计算机存储中，零任何隐私或域名上传。

## 🚀 使用方法
1. 前往 [Releases](https://github.com/Umbra-ye/SubFlow/releases) 下载 `SubFlow-v2.0-Desktop.zip`；
2. 解压至任意目录，双击运行 `SubFlow.exe` 即可立即使用！
